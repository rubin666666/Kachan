# Від першої сторінки до власного сайту

## Порядок навчання

1. «Почни з нуля»: файл, браузер, адреса, редактор та інструменти розробника.
2. HTML: структура, текст, посилання, зображення, форми й доступність.
3. CSS: каскад, коробки, одиниці, типографіка, Flexbox, Grid, адаптивність і компоненти.
4. JavaScript: значення, порівняння, умови, цикли, рядки, масиви, об’єкти, async, DOM і маленький застосунок.
5. Чотири практичні проєкти: адаптивне меню → галерея → пошук → API-клієнт.
6. Портфоліо: спільні HTML/CSS/JS-файли, перевірки, експорт ZIP, Git і самостійна публікація.

У навчанні кожен приклад відокремлений від основного завдання. Розбір пояснює, що відбувається на кожному кроці, пропонує спочатку передбачити результат і лише потім запускати код. Посилання на основне завдання пояснює, що селектори маленького прикладу можуть відрізнятися від селекторів вправи.

## Практика

- 18 тем CSS/JavaScript отримали докладніші двомовні пояснення, три кроки розбору та питання на передбачення результату.
- Тренажер помилок містить 14 вправ HTML/CSS/JS. Три рівні підказок відкриваються поступово й зберігаються.
- Звичайні CSS-перевірки показують обчислене й очікуване значення. Нові проєкти та тренажери додають контекстну підказку, а помилки виконання — пояснення, де почати пошук.
- Чотири проєкти зберігають окремі чернетки та результати в `extras.preferences.learningProjects`. Старі резервні копії без цього поля сумісні.

## Межі перевірок

Меню перевіряється на 390px та 900px: зв’язок кнопки з nav, початковий стан, відкриття, Escape і видимість широкої навігації. Галерея використовує три локальні SVG-ілюстрації, перевіряє вибір, лічильник та циклічні стрілки клавіатури. Пошук перевіряє регістр, пробіли, порожній результат, очищення та відсутність вставленого HTML.

API-проєкт навмисно використовує локальну підміну `fetch` із затримкою. Є success, empty, HTTP error та network error. Перевіряються loading, вимкнення/відновлення кнопки, очищення списку та відмінність порожньої відповіді від помилки. ZIP містить явно позначену підміну, щоб приклад працював і без сервера. Перед підключенням справжнього API її потрібно прибрати та обрати власний endpoint. Секретні ключі в frontend не потрібні для цих вправ.

Це автоматизований навчальний чекліст, не повний аудит дизайну чи доступності. Перед публікацією потрібно вручну перевірити Tab/Shift+Tab/Enter, масштаб тексту, довгі написи й різні ширини. Kachan експортує файли та пояснює GitHub Pages; сам навчальний сайт користувача не публікує.

## Перевірка шляху

- `tests/learning-expansion.cjs`: усі 18 тем двома мовами, початкові та робочі розв’язки чотирьох проєктів, виконання коду, підказки, ZIP, відновлення та збереження старих чернеток.
- `tests/practice-expansion.cjs`: вісім доданих задач, три підказки та фактичні CSS-значення в основному уроці.
- `tests/learning-project-layout.cjs`: 48 поєднань проєкту, мови, теми та ширини.
- `tests/learning-project-export.cjs`: усі чотири сайти запускаються під окремим підкаталогом, як на GitHub Pages; перевіряються їхні дії та офлайн-відновлення чернетки.
- `tests/portfolio-course.cjs`: маршрут HTML → CSS → JS → Git, ZIP із перевіркою CRC, запуск окремого сайту, ручне підтвердження публікації й офлайн-збереження.
