# Навчання у Kachan

Маршрут має **34 базові уроки**. Це початковий маршрут, а не енциклопедія всіх можливостей технологій.

| Модуль | Уроки | Теми |
|---|---:|---|
| HTML | 10 | Структура, текст, посилання, списки, зображення, семантика, форми, таблиці, доступність, портфоліо |
| CSS | 6 | Каскад, блокова модель, Flexbox, Grid, адаптивність і фокус, картки |
| JavaScript | 6 | Значення й функції, масиви, об’єкти, async/API, DOM і події, модель задач |
| Git | 6 | Init/status, staging/commit, branches, merge, remote/fetch/push, робочий цикл |
| TypeScript | 6 | Типи, unions, interfaces, generics, narrowing/unknown, типізовані задачі |

Кожний новий урок має мету, пояснення, завдання, дві підказки, перевірки, короткий тест із поясненням і приклад після першої спроби. Фінальний урок кожного модуля — мініпроєкт із самоперевіркою.

Завершення нового уроку потребує прочитаної теорії, пройденої практики та правильного тесту. Для мініпроєкту потрібна ще самоперевірка. Зміна коду скасовує результат практики до наступної перевірки. Чернетки, відповіді, підказки й прогрес зберігаються автоматично.

## Межі перевірок

- HTML: DOMParser перевіряє структуру. Скрипти у його прев’ю не виконуються.
- CSS: HTML/CSS показуються у sandbox. Частина умов оцінює computed style, частина — потрібні конструкції в тексті. Ширини прев’ю: 320/600/900px. Красу, усі breakpoints і всю доступність умови не оцінюють.
- JavaScript: чисті функції виконуються в Worker усередині iframe з окремим opaque origin, із таймаутом, без мережі й доступу до даних Kachan. Урок API має локальну тестову відповідь. DOM-урок виконується в sandbox-прев’ю: перевірка натискає кнопку й перевіряє результат. Цикли та функції мають ліміт кроків; динамічний код і таймери недоступні. Це навчальний редактор для власного коду, не середовище для запуску недовірених сторонніх програм. Вкладки HTML/CSS/JS зберігають окремі чернетки.
- Git: навчальна симуляція обмеженого набору команд. Реальна папка, shell та GitHub не змінюються. Справжні текстові конфлікти не симулюються.
- TypeScript: локальний офіційний компілятор 5.9.3, strict, ES2022/DOM, повідомлення з рядком/колонкою. Після успішної компіляції JavaScript виконується в ізольованому Worker. Зовнішні модулі не підтримуються. Компілятор і бібліотеки кешуються для офлайн.

## Зв’язки та повторення

Із уроку можна створити конспект або додати картку повторення. У нотатці окремо обираються проєкт, задача й урок. Календар показує строки карток; «Пам’ятаю» збільшує інтервал, «Повторити завтра» встановлює один день.

Матеріали оригінальні, українською й англійською. Подальші розширення можуть додати складніші проєкти та ширше покриття API.
