# 40 пунктів: реалізація в Kachan

Це перші робочі версії можливостей, інтегровані в наявні розділи. Після редизайну 22 активності Студії та 13 основних інструментів об’єднані в єдиний каталог «Інструменти» зі спільним пошуком і фільтрами. Частина пунктів використовує спільний екран, а частина стосується загального дизайну. Новий пункт у sidebar не додавався.

## Функціонал 1–20

| № | Можливість | Де знайти та що працює |
|---|---|---|
| 1 | Пошук із переглядом | Глобальний пошук показує короткий опис. Студія → Пошук має окрему панель опису перед відкриттям. |
| 2 | Закріплене | Пошук у Студії → Закріпити. До 8 матеріалів видно у розкривному блоці головної. Обрані ресурси також доступні окремим фільтром. |
| 3 | Історія | До 30 останніх уроків, інструментів, ресурсів і активностей. Можна очистити лише історію. |
| 4 | Порівняння коду | Два редактори й LCS-порівняння перших 200 рядків, додані/видалені рядки мають колір і символ. |
| 5 | Покроковий JS | map, цикл із сумою та click зі станом після кожного кроку; назад і спочатку. |
| 6 | Палітри | Три кольори, реальний розрахунок контрасту текст/фон, експорт CSS-змінних. |
| 7 | Типографіка | Розмір, масштаб заголовків, line-height, три сімейства та живий зразок, CSS для копіювання. |
| 8 | Маршрут | Карта шести напрямків із передумовами, прогресом та наступним уроком. |
| 9 | Порожні стани | Пошук, історія, закріплене, повторення, полотно й презентація пояснюють наступну дію. |
| 10 | Деталі дизайну | Спільні розміри контролів, фокус, відступи, адаптивність, результати перевірок і reduced motion. |
| 11 | CSS-інспектор | Вибір елемента кліком або select, реальний getComputedStyle і геометрія, зміна padding. Це навчальний зразок, не інспектор чужих сайтів. |
| 12 | Помилки | Шість зламаних HTML/CSS/JS-прикладів, підказки, справжні DOM/обчислені CSS/JS-перевірки. |
| 13 | За макетом | Відтворення картки CSS за живим зразком із перевіркою чотирьох умов. |
| 14 | Шпаргалки | Словник із кодом і копіюванням, панель довідки поруч із редактором робочого столу. |
| 15 | Терміни | 12 пояснень; контекстні терміни в поясненнях уроків відкривають відповідний запис словника. |
| 16 | Анімації | Відстань, тривалість, easing, запуск/скидання та CSS. У reduced motion показується кінцевий стан. |
| 17 | Доступність | Виправлення label, required, кнопки та видимого фокусу. Клавіатуру перевіряє користувач; це не повний аудит WCAG. |
| 18 | Браузер | П'ять кроків HTML → CSSOM → Layout → Paint → Composite зі схемою та поясненням спрощень. |
| 19 | Повторення | По одному питанню для шести тем; список формується з реально завершених відповідних уроків. До навчання можна спробувати позапрогресове питання HTML. |
| 20 | Розбір компонентів | Картка, меню, форма: три кроки, пояснення, код та ізольований результат. |

| 32 | Маскот | Авторський SVG-качан у вступі Студії, головній та коміксах. Без зовнішніх зображень і бібліотек. |
| 33 | Сузір'я | Карта перемикається між маршрутом і сузір'ям, вузли відкривають теми та передумови. |

| 35 | Галерея | Три CSS-постери з керуванням композицією та базовим кодом для власних експериментів. |
| 36 | Картки | Шість авторських карток навичок відкриваються після практики відповідного напряму. Не сертифікати. |
| 37 | Комікси | Три історії по три панелі: HTTP-подорож, каскад CSS та обробка події. |
| 38 | Презентація | Вибір реального проєкту, рамка ноутбука/телефона, повний екран. Сайт завантажується лише після натискання; доступний окремий перехід при забороні вбудовування. |
| 39 | Полотно | До 20 блоків, текст, drag-and-drop і клавіатурне переставляння, ізольований результат та експорт HTML із CSS. |
| 40 | Теми | Graphite, Paper, Terminal; збереження вибору та повернення стандартного стилю. |

## Дані та перевірки

Новий стан — необов'язкове поле `extras.preferences.studio`. Його перевіряє `validStudio` до читання даних. Палітра, типографіка, полотно, чернетки, закріплене, історія й результати входять у чинну JSON-копію та хмарний snapshot. Чернетки уроків і пісочниці залишаються окремими.

- `tests/studio-workflows.cjs`: правильні й неправильні рішення, експорт, редактор, історія, теми та перезавантаження.
- `tests/studio-design.cjs`: числові значення дизайну, карта, комікси, картки навичок, повторення й глобальний пошук.
- `tests/studio-layout.cjs`: 528 поєднань активності, двох мов, чотирьох варіантів теми та трьох ширин. Декоративні постери з навмисним обрізанням графіки не вважаються обрізаним текстом.

Запуск: Node + Playwright. `KACHAN_TEST_URL` може вказувати на локальний або публічний сайт.
