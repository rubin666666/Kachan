# Kachan — план розвитку

Це список майбутніх можливостей, а не опис уже готових функцій. Реалізуємо послідовно, без переходу на фреймворк тільки заради фреймворка.

## Уже готово в поточному етапі

- Редагування задач зі збереженням стану виконання.
- Прив’язка задачі до проєкту.
- Низький, середній і високий пріоритет.
- Дедлайн та позначка прострочених задач за датою Europe/Kyiv.
- Сортування за порядком додавання, дедлайном та пріоритетом.
- Прогрес проєкту за виконаними задачами; без задач використовується ручний прогрес.
- Список пов’язаних задач на картці проєкту з checkbox.
- Перевірка резервних копій із новими полями задач.
- Мобільне меню, відступи, елементи керування, світлі смуги прогресу, контраст акцентів і тимчасові повідомлення.

## 1. Навчання з практикою — найвищий пріоритет

Зараз Learning містить перелік тем із checkbox. Наступний етап — повноцінні навчальні матеріали та вправи.

- [ ] Побудувати маршрут HTML → CSS → JavaScript → Git → TypeScript.
- [ ] Розділити технології на модулі й уроки.
- [ ] Додати пояснення теми з короткими прикладами.
- [ ] У кожному уроці показувати очікуваний результат навчання.
- [ ] Додати завдання після пояснення.
- [ ] Позначати складність: початкова, середня, складна.
- [ ] Створити практику HTML: семантика, форми, таблиці, доступність.
- [ ] Створити практику CSS: Flexbox, Grid, адаптивність, позиціонування.
- [ ] Створити практику JavaScript: масиви, об’єкти, DOM, події, fetch.
- [ ] Додати підказки, які відкриваються по черзі.
- [ ] Приховувати приклад розв’язку до самостійної спроби.
- [ ] Створити редактор HTML/CSS/JS із запуском у sandbox iframe.
- [ ] Додати автоматичні перевірки там, де результат можна надійно перевірити.
- [ ] Для дизайнерських завдань додати checklist для самоперевірки.
- [ ] Показувати причину помилки й приклад очікуваного результату.
- [ ] Зберігати розв’язки й чернетки практичних вправ.
- [ ] Додати стани: не почато, в процесі, завершено, повторити.
- [ ] Створити невеликі підсумкові проєкти після модулів.
- [ ] Додати короткі тести й запитання для повторення.
- [ ] Показувати окремо прогрес теорії та практики.

## 2. Notes — особистий блокнот

- [ ] Додати пункт Notes / Нотатки в меню.
- [ ] Створювати, редагувати й видаляти нотатки.
- [ ] Автоматично зберігати текст із помітним станом збереження.
- [ ] Додати заголовок і дату останнього редагування.
- [ ] Почати з простого тексту, потім додати Markdown та preview.
- [ ] Додати папки або категорії: навчання, ідеї, проєкти, помилки.
- [ ] Додати теги, пошук і сортування.
- [ ] Закріплювати важливі нотатки.
- [ ] Прив’язувати нотатку до проєкту, задачі або уроку.
- [ ] Створити шаблони: конспект, ідея, звіт за день, розбір помилки.
- [ ] Додати списки справ усередині нотаток.
- [ ] Додати корзину й відновлення видалених нотаток.
- [ ] Експортувати окрему нотатку у .md / .txt.
- [ ] Включити нотатки до загального JSON backup із підтримкою попередніх версій.

## 3. Dashboard для щоденної роботи

- [ ] Блок «Сьогодні»: найближчі й прострочені задачі.
- [ ] Кнопки швидкого створення задачі, проєкту та нотатки.
- [ ] Продовження останнього уроку або практики.
- [ ] Останні нотатки та закріплені матеріали.
- [ ] Ціль на день або тиждень.
- [ ] Історія активності на основі реальних дій користувача.
- [ ] Графік завершених задач та навчальних сесій.
- [ ] Налаштування порядку й видимості блоків.

## 4. Projects і Tasks

- [ ] Окрема сторінка деталей проєкту.
- [ ] Нотатки, ресурси й snippets усередині проєкту.
- [ ] Етапи проєкту та підзадачі.
- [ ] Kanban: заплановано, в роботі, завершено.
- [ ] Фільтр задач за проєктом та пріоритетом.
- [ ] Архів проєктів без видалення історії.
- [ ] Повторювані задачі.
- [ ] Відновлення випадково видаленої задачі.
- [ ] Масові дії: завершити, змінити пріоритет, перенести.
- [ ] Вибір ручного чи автоматичного прогресу проєкту.

## 5. Snippets і Resources

- [ ] Підсвічування синтаксису коду.
- [ ] Теги, обране та закріплені snippets.
- [ ] Зв’язок snippet із уроком або проєктом.
- [ ] Завантаження snippet як файлу.
- [ ] Додавання власних ресурсів замість лише початкового списку.
- [ ] Пошук ресурсів та особисті коментарі до них.
- [ ] Списки ресурсів під конкретну тему або навчальний маршрут.

## 6. Фокус і повторення

- [ ] Pomodoro або простий таймер навчання.
- [ ] Прив’язка сесії до задачі чи уроку.
- [ ] Історія часу без вигаданих показників.
- [ ] Картки запитань для повторення.
- [ ] План повторення пройдених тем.
- [ ] Нагадування про дедлайни, лише після згоди на сповіщення.

## 7. Зручність і доступність

- [ ] Глобальний пошук по всіх розділах.
- [ ] Командна палітра та гарячі клавіші.
- [ ] Налаштування розміру тексту й компактності.
- [ ] Тема відповідно до системних налаштувань.
- [ ] Додаткова перевірка screen reader та керування клавіатурою.
- [ ] Індикатор незбережених змін у формах.
- [ ] Завантаження та помилки в однаковому стилі для всіх API.

## 8. Надійність і подальша технічна частина

- [ ] Версіювання збережених даних і міграції.
- [ ] Імпорт із об’єднанням даних, окрім поточної заміни.
- [ ] IndexedDB, коли нотаток і коду стане забагато для LocalStorage.
- [ ] Автоматичні регресійні перевірки важливих дій.
- [ ] PWA: встановлення як застосунку та робота офлайн.
- [ ] Авторизація та backend, коли буде потрібна синхронізація між пристроями.
- [ ] Хмарні резервні копії та конфлікти одночасного редагування.
- [ ] TypeScript після стабілізації моделей даних.
- [ ] React лише якщо розмір і взаємодія інтерфейсу виправдають перехід.

## Рекомендована послідовність

1. Notes: базовий блокнот з автозбереженням і backup.
2. Learning: кілька повних уроків і практичних вправ з HTML/CSS.
3. Практичний редактор із preview та перевірками.
4. Зв’язки між навчанням, нотатками й проєктами.
5. Блок «Сьогодні», фокус-таймер і повторення.
6. PWA та синхронізація, коли вони стануть потрібні.
